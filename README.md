# Water Potability Prediction

## Project Overview
This project predicts whether water is safe for drinking using machine learning algorithms and data analysis techniques.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## Machine Learning Models
- Random Forest
- SVM
- KNN
- XGBoost
- AdaBoost

## Workflow
1. Data Cleaning
2. Missing Value Handling
3. Exploratory Data Analysis
4. Model Building
5. Model Evaluation

## Results
Random Forest achieved the best performance after tuning and sampling techniques.
