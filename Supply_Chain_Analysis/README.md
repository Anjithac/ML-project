## 🔍 Project Overview

This project analyzes supply chain data to understand profitability, delivery delays, operational bottlenecks, and factors affecting overall performance. Python-based data analysis and machine learning are used to identify patterns and support data-driven business decisions.

## 🎯 Objectives

- 📊 Analyze profitability and key performance indicators (KPIs).
- 🚚 Explore delivery delays and their distribution.
- 🔎 Identify operational bottlenecks and potential root causes.
- 📅 Discover time-based patterns in delivery delays.
- 🤖 Apply machine learning to analyze supply chain performance.
- 💡 Recommend strategies to improve operational efficiency.

## 🔄 Project Workflow

1. 📥 **Data Loading** — Import the supply chain dataset.
2. 🧹 **Data Preprocessing** — Inspect and prepare the data for analysis.
3. 📊 **Exploratory Data Analysis** — Examine KPIs, profitability, and delivery delays.
4. 🔍 **Bottleneck Analysis** — Investigate delay patterns and possible contributing factors.
5. 🤖 **Machine Learning** — Train and evaluate a Random Forest model.
6. 💡 **Recommendations** — Identify opportunities for operational improvement.

## ▶️ How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/Anjithac/Supply-Chain-Analysis.git
   ```

2. Open the project folder:

   ```bash
   cd Supply-Chain-Analysis
   ```

3. Install the required libraries:

   ```bash
   pip install pandas numpy matplotlib seaborn scikit-learn imbalanced-learn jupyter
   ```

4. Start Jupyter Notebook:

   ```bash
   jupyter notebook
   ```

5. Open `supply_chain_analysis.ipynb` and run the cells.
